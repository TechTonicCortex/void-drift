# Void Drift

**A space-flying game where you rotate and thrust, like a real ship in space.**
Open `index.html` in a browser.

## Controls
**Arrow keys or WASD** to rotate and thrust. Click **LAUNCH** to start and **RETRY** to try again.

## How it works
Movement uses **momentum**. In space nothing stops you, so thrust adds to your speed and you keep drifting until you thrust the other way. An arrow shows direction on screen.

## What I learned
Why space movement feels different from walking: speed carries on, so you have to plan ahead.
